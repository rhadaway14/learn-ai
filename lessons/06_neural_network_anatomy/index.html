01

Neural networks learn intermediate representations

A linear model maps inputs directly to an output. A neural network inserts one or more hidden layers. Those layers learn intermediate combinations that can represent interactions, thresholds, curves, and reusable patterns.

LINEAR MODEL

One learned transformation

Project risk changes along one flat boundary defined directly from the original features.

NEURAL NETWORK

Composed learned transformations

Hidden layers can build representations such as “large migration with weak staffing and a short deadline.”

Metaphor: an assembly line for information

Each station receives a representation, transforms it, and passes a new representation onward. Early stations can detect simple signals; later stations combine them into decision-relevant patterns.

Where the metaphor stops: hidden features are learned jointly rather than assigned to human-readable stations, and a neuron does not reason or hold a biological concept.

Input layer

The feature vector entering the network.

Project size, integrations, staffing, deadline.

Hidden layer

An intermediate learned representation.

Not directly supplied as a label.

Output layer

Values shaped for the prediction task.

Effort estimate or late-risk score.

Forward pass

Compute outputs from inputs using current parameters.

No parameter update occurs by itself.

02

A neuron computes a weighted sum, adds a bias, then activates

For each input, a learned weight controls influence. The neuron adds the weighted inputs and a learned bias to produce a pre-activation value, commonly called z. An activation function then transforms z.

inputs × weights → add the results → add bias → apply activation

Worked neuron

Suppose project complexity is 2 with weight 0.8, urgency is 3 with weight −0.4, and bias is 0.5.

2 × 0.8 = 1.63 × −0.4 = −1.2+ 0.5 biasz = 0.9

If the activation is ReLU, the output remains 0.9 because ReLU keeps positive values.

Go deeper: compact neuron notation

The equation compresses the weighted sum students have already calculated:

a = f(w₁x₁ + w₂x₂ + … + wₙxₙ + b)

xᵢ is input i, wᵢ is its learned weight, b is the learned bias, f is the activation function, and a is the neuron's output.

Metaphor: a weighted review rubric

A reviewer scores several criteria, gives each criterion a different importance, adds a baseline adjustment, and passes the total through a decision rule.

Where the metaphor stops: real neurons learn numerical weights from data, hidden outputs need not have a human-readable meaning, and thousands of neurons operate together.

03

A dense layer runs many neurons in parallel

Every neuron in a fully connected or dense layer receives every input feature. Each neuron owns a different weight for each input and one bias, so each can learn a different combination.

Metaphor: several reviewers reading the same intake form

Every reviewer sees all fields but uses a different rubric. Their scores become a new feature vector for the next team.

Where the metaphor stops: neurons do not independently choose specialties; their roles emerge from joint optimization, and dense connectivity may not be efficient for every data type.

Shape tells us whether the transformation can connect

Using row-oriented examples, an input batch shaped (batch, inputs) multiplies weights shaped (inputs, outputs). A bias with one value per output is reused across every example.

(batch, inputs) × (inputs, outputs) + (outputs) → (batch, outputs)
Framework convention note: this lesson writes weights as (inputs, outputs) to match XW + b. Some libraries store the same weights transposed as (outputs, inputs). The mapping is identical; always inspect the documented convention.

LEARNED PARAMETERS

04

Activation functions decide how a neuron responds

The weighted sum alone is linear. An activation changes the signal before the next layer. Different activations have different ranges, shapes, and training behavior.

ReLU

Returns 0 for negative inputs and keeps positive inputs.

Fast and common in hidden layers; units can become inactive.

Sigmoid

Compresses values into the range 0 to 1.

Useful for bounded binary output scores; saturates at extremes.

Tanh

Compresses values into the range −1 to 1.

Zero-centered, but also saturates at extremes.

Linear

Returns the input unchanged.

Useful for many regression outputs; insufficient between every hidden layer.

Saturation: sigmoid and tanh become nearly flat at large positive or negative inputs. Their local slopes approach zero, so learning signals can shrink as they pass through many saturated layers.

At exactly z = 0: ReLU has a sharp corner, so its mathematical derivative is undefined there. Training libraries choose a usable convention, commonly slope 0.

05

Without nonlinear activations, depth collapses into one linear map

Two linear layers may contain many parameters, but their combined effect is still one linear transformation. Adding more linear-only layers does not create curved or folded decision boundaries.

Why the layers collapse

First layer: multiply x by 2 and add 1. Second layer: multiply that result by 3 and add 4.

3 × (2x + 1) + 4 = 6x + 7

The two steps can be replaced by one multiplication and one bias. A nonlinear activation between them prevents that algebraic collapse.

Metaphor: folding a map

Linear transformations can rotate, stretch, shift, or shear a sheet while it stays flat. Nonlinear activations introduce folds, allowing later layers to separate patterns that a single straight cut cannot.

Where the metaphor stops: high-dimensional neural transformations are not literal paper folds, and learned representations can be far more complex than a visible two-dimensional boundary.

NONLINEARITY LAB

Separate the XOR pattern

Blue corners are positive when exactly one input is on. A single straight boundary cannot isolate both diagonal blue corners from both gray corners.

06

Width, depth, and parameter count shape model capacity

Width

The number of neurons in a layer. More width lets a stage represent more features in parallel.

Depth

The number of learned transformations. More depth supports hierarchical composition.

Capacity

The range and complexity of functions a model can represent. Parameter count is one clue, not the whole story.

Metaphor: specialists and stages

Width resembles adding specialists at one processing stage. Depth resembles adding successive stages that build on earlier work.

Where the metaphor stops: neurons are not people, equal parameter counts can behave differently, and optimization, data, regularization, and architecture all affect effective capacity.

REGRESSION

One or more linear outputs

Predict an unrestricted numeric amount, unless the domain requires a bounded output.

BINARY CLASSIFICATION

One logit, then sigmoid

A logit is the unrestricted weighted score defined in Lesson 5. Sigmoid maps it between 0 and 1 before a decision threshold.

MULTICLASS CLASSIFICATION

One logit per class, then softmax

Softmax compares every class logit and turns them into positive shares that sum to 1.

Softmax with three class logits

Suppose the logits for on time, slightly late, and severely late are [2.0, 1.0, 0.1]. Exponentiation makes every value positive: [7.39, 2.72, 1.11]. Their sum is 11.22. Divide each positive value by that sum:

[7.39 ÷ 11.22, 2.72 ÷ 11.22, 1.11 ÷ 11.22] = [0.659, 0.242, 0.099]

The outputs sum to 1 and preserve the ranking. They are model confidence scores, not automatically calibrated real-world probabilities; representative validation evidence must establish calibration.

Two unrelated uses of “residual”: a residual error is prediction minus label. A residual or skip connection in a later network architecture adds an earlier representation to a later one so information and gradients have a shorter path.

Shape mismatch

Adjacent widths do not connect. Diagnose by writing every tensor shape before multiplying.

Missing nonlinearity

Many layers collapse to one linear map. Inspect the architecture between learned transforms.

Dead ReLU

A unit remains on the zero side and stops responding. Inspect activation and gradient distributions.

Saturation

Extreme sigmoid or tanh inputs have near-zero slopes. Inspect pre-activations and local gradients.

Engineer deep dive · capacity, scale, and architecture risk

Turn the concept into an engineering contract

Start by naming the input, output, units, axes, valid ranges, and lifecycle boundary for every value involved. Record which facts exist at training time, prediction time, and only after the outcome. Add invariants that a program or reviewer can check: shapes agree, values are finite, identifiers do not cross split boundaries, and repeated execution with the same seed stays within a declared tolerance. A successful calculation is not enough; the result must retain its meaning at every interface.

Verify mechanics with a known-answer case

Build the smallest example that can be calculated independently, then preserve its inputs and expected intermediate values as a regression test. Check more than the final number. Inspect the state before the operation, the state immediately afterward, and the evidence used by the next operation. Compare a hand-worked case, a trusted reference implementation, and the production path. When they disagree, change one factor at a time. This separates a mathematical defect from indexing, reduction, precision, initialization, or data-contract defects.

Run a controlled failure experiment

Write a prediction before changing anything: name the control, the expected failure signal, and the recovery condition. Perturb one assumption deliberately, such as scale, ordering, sample composition, initialization, or a boundary value. Keep the original evidence and configuration so the comparison remains causal. The system should fail visibly and safely rather than produce a plausible but invalid answer. Restore the known-good state, rerun the same verification, and retain both the failure and recovery records.

Instrument the mechanism, not only the outcome

Aggregate quality metrics can improve while an internal mechanism is failing. Capture distributions and counts for the quantities this section introduces, segmented by meaningful slices and accompanied by sample size. Track missing and nonfinite values, extrema, representative quantiles, drift from a reference run, and the rate at which guardrails activate. Establish an expected range from validation evidence before choosing alert thresholds. Logs should identify the dataset, configuration, model or artifact version, and execution stage without exposing sensitive records.

Reason about scale and operational cost

Estimate how work and memory grow with examples, features, parameters, and any pairwise dimensions. Distinguish persistent state from temporary activations and useful compute from data movement, serialization, and synchronization. Measure representative workloads rather than extrapolating from one tiny example. State the latency, throughput, memory, and numerical precision budget, then identify which approximation or batching decision could violate the learning contract. Performance changes require the same correctness evidence as algorithm changes.

Define promotion, rollback, and ownership

A reviewable artifact includes data lineage, configuration, environment, seeds, assumptions, acceptance thresholds, known limitations, and the exact command or interaction that reproduces the result. Promotion should require protected evaluation evidence and an explicit owner. Rollback should name a previously verified artifact and the signal that triggers restoration. Monitor the deployment population for the assumptions made here; when those assumptions stop holding, route the system to a safe behavior and reopen the engineering decision instead of silently trusting yesterday's evidence.

Prerequisites: matrix shape tracing from Lesson 2 and the weight, bias, activation, loss, and parameter concepts introduced in Lessons 1–5.

A dense layer performs a matrix transformation plus bias; an activation adds nonlinearity. Without nonlinear activations, stacked dense layers collapse to one linear transformation. Width affects capacity, depth affects composition, initialization affects early signal scale, and shapes determine parameter count and compute.

Parameters grow roughly with input width times output width; activation memory grows with batch size times width. Wrong shapes stop execution, saturated activations weaken gradients, excess width wastes memory, and insufficient capacity underfits.
