The shapes of AI data

AI systems organize numbers into scalars, vectors, matrices, and tensors. You will learn to read their shapes, combine them safely, and see why these operations power neural networks, embeddings, and attention.

01

Numbers become useful when their axes have meaning

A tensor is an organized collection of numbers. Its rank tells us how many axes it has. Its shape tells us the length of each axis. Neither tells us what an axis means—the engineer must preserve that meaning.

RANK

How many axes?

A matrix has two axes, so its tensor rank is 2. A batch of color images often has four axes.

SHAPE

How long is each axis?

A matrix with 4 rows and 3 columns has shape (4, 3). Shape is an ordered description.

Context warning: “tensor rank” means number of axes. “Matrix rank” is a separate linear-algebra idea about independent rows or columns. This lesson uses tensor rank.

BEFORE WE USE THE WORD TOKEN

A token is a piece of input assigned a vocabulary ID

A language model does not receive sentences directly. A tokenizer divides text into vocabulary pieces and replaces each piece with an integer ID. A token might be a whole word, part of a word, punctuation, or whitespace—the exact pieces depend on the tokenizer.

“unbelievable!”tokenizer[“un”, “believ”, “able”, “!”]IDs[412, 9, 81, 7]

Those pieces are illustrative, not universal. After lookup, every token ID becomes a vector of learned numbers. In a tensor, a token position means one ordered slot in that sequence—not necessarily one word.

Go deeper: axes are a contract

Shape (8, 128, 768) is incomplete without names. In a language model it might mean 8 text sequences processed together, 128 token positions per sequence, and a 768-number learned representation for every token position.

Swapping axes can preserve the same number of values while changing their meaning. Correct AI engineering tracks both dimensions and semantics at every boundary.

02

A vector is an ordered description

A vector is a one-axis tensor. Its components only become meaningful when their order is defined. The vector [1,800, 3, 12] could represent square feet, bedrooms, and age—but only if every example follows that same order and unit convention.

Feature vector

Several measured properties describing one example.

[size, rooms, age]

Embedding

A learned vector whose geometry represents useful relationships.

[0.82, −0.14, …]

Activation

Intermediate values produced inside a neural network.

one layer's current state

Element-wise operations

Vector addition combines matching positions. It is valid only when vectors have compatible shapes and corresponding components carry compatible meaning.

[1, 2, 3] + [4, 5, 6] = [5, 7, 9]
Why addition matters in AI

Addition lets a model combine compatible information without replacing either source. A transformer adds a token embedding to a position embedding so the representation carries both what token this is and where it occurs. Residual connections add a layer's input back to its output, preserving an information path through a deep network. Bias addition shifts every example by learned adjustments.

Addition only makes sense when positions refer to the same coordinate system. Adding two equally long but unrelated vectors can run successfully and still be meaningless.

Magnitude

Magnitude measures vector length. Square each component, add the squares, and take the square root. For [3, 4], the squared components are 9 and 16; their sum is 25; the square root is 5.

Why magnitude matters in AI

Magnitude tells us the overall scale of a vector. It is used to normalize embeddings before comparing their directions, to measure the size of a gradient update, and to detect activations or gradients that are becoming extremely large. Two vectors can point in the same direction while having very different magnitudes, which is why dot product and cosine similarity answer different questions.

03

The dot product turns two vectors into one score

The dot product answers: how strongly do corresponding components align and reinforce one another? Multiply matching positions, then add the products.

Worked example

(1 × 4)+(2 × −1)+(3 × 2)=8

Positive component products raise the score; negative products lower it. The final output is a scalar.

Why one score is useful

A model often needs to collapse many component-by-component comparisons into one decision signal. In a neuron, the score says how strongly the current inputs match that neuron's learned weights. In retrieval, it can rank how well a query vector matches a document vector. In attention, it helps decide how much one token position should use information from another position.

A larger dot product can come from stronger directional alignment, larger magnitudes, or both. When only direction should matter, systems often normalize the vectors and use cosine similarity.

Go deeper: why neural networks use dot products

A neuron treats one vector as inputs and another as weights. Their dot product forms a weighted sum: inputs paired with larger positive weights contribute more, while negative weights suppress the result.

Attention also begins with dot products. A query vector receives a larger score for key vectors that align with it. Later lessons add scaling, masking, and normalization.

04

Matrices transform batches of vectors

A matrix is a two-axis tensor: rows and columns. A data matrix often stores one example per row and one feature per column. Matrix multiplication applies many dot products systematically.

What “transformation” means here

A transformation maps a vector from one representation to another. Multiplying by a learned weight matrix mixes the input components to produce new components. A layer can turn 10 input measurements into 8 learned features, or turn each transformer token vector into separate query, key, and value vectors.

Geometrically, a matrix can stretch, shrink, rotate, reflect, or combine directions. In machine learning, training adjusts the matrix values until that new representation becomes useful for the prediction task. The operation changes the representation; it does not change which example or token the row belongs to.

Transpose swaps two axes

05

Broadcasting reuses a compatible smaller shape

Suppose a batch produces 3 output values for each of 4 examples. The result shape is (4, 3). A bias vector with shape (3,) contains one adjustment per output feature. Broadcasting adds that same bias vector to every row.

WATCH THE REUSE

+
Bias (3,)
→
Output (4, 3)

The bias has one value for each column, so it can be reused across rows.

Convenient does not mean harmless. An accidentally compatible shape can produce a valid calculation with the wrong meaning. Name axes, assert expected shapes, and test known examples.

06

Embeddings turn meaning into geometry

An embedding model maps an object—such as a word, document, image, or product—to a vector. Training arranges vectors so that geometric relationships become useful for the model's objective.

Cosine similarity compares direction after accounting for magnitude. It divides the dot product by both vector lengths. Values near 1 point in similar directions, 0 indicates a right angle, and −1 indicates opposite directions.

Go deeper: similarity is not understanding

An embedding is learned for an objective and dataset. Nearby vectors indicate similarity according to that training signal, not a universal definition of meaning.

Production retrieval also depends on normalization, distance choice, indexing, metadata filters, data freshness, reranking, and evaluation. A similarity score alone is not proof that a result is relevant.

07

Tensor shapes describe transformer computation

A common activation shape is (batch, sequence, hidden): several text sequences processed together, several ordered token positions in each sequence, and one learned vector at every position.

Example: suppose a tokenizer turns “Models learn patterns.” into five model-specific tokens. That one sentence has sequence length 5. If it is padded to 8 positions and processed with three other sentences, the batch has 4 sequences and sequence length 8. With 768 learned values per token position, its activation shape is (4, 8, 768).

The token itself begins as an integer vocabulary ID. The hidden vector is the model's changing numeric representation of that token in context. They are related, but they are not the same thing.
