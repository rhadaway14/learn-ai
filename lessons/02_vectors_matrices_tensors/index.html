01

Numbers become useful when their axes have meaning

A tensor is an organized collection of numbers. Its rank tells us how many axes it has. Its shape tells us the length of each axis. Neither tells us what an axis means—the engineer must preserve that meaning.

RANK

How many axes?

A matrix has two axes, so its tensor rank is 2. A batch of color images often has four axes.

SHAPE

How long is each axis?

A matrix with 4 rows and 3 columns has shape (4, 3). Shape is an ordered description.

Context warning: “tensor rank” means number of axes. “Matrix rank” is a separate linear-algebra idea about independent rows or columns. This lesson uses tensor rank.

BEFORE WE USE THE WORD TOKEN

A token is a piece of input assigned a vocabulary ID

A language model does not receive sentences directly. A tokenizer divides text into vocabulary pieces and replaces each piece with an integer ID. A token might be a whole word, part of a word, punctuation, or whitespace—the exact pieces depend on the tokenizer.

“unbelievable!”tokenizer[“un”, “believ”, “able”, “!”]IDs[412, 9, 81, 7]

Those pieces are illustrative, not universal. After lookup, every token ID becomes a vector of learned numbers. In a tensor, a token position means one ordered slot in that sequence—not necessarily one word.

Go deeper: axes are a contract

Shape (8, 128, 768) is incomplete without names. In a language model it might mean 8 text sequences processed together, 128 token positions per sequence, and a 768-number learned representation for every token position.

Swapping axes can preserve the same number of values while changing their meaning. Correct AI engineering tracks both dimensions and semantics at every boundary.

02

A vector is an ordered description

A vector is a one-axis tensor. Its components only become meaningful when their order is defined. The vector [1,800, 3, 12] could represent square feet, bedrooms, and age—but only if every example follows that same order and unit convention.

Feature vector

Several measured properties describing one example.

[size, rooms, age]

Embedding

A learned vector whose geometry represents useful relationships.

[0.82, −0.14, …]

Activation

Intermediate values produced inside a neural network.

one layer's current state

Element-wise operations

Vector addition combines matching positions. It is valid only when vectors have compatible shapes and corresponding components carry compatible meaning.

[1, 2, 3] + [4, 5, 6] = [5, 7, 9]
Why addition matters in AI

Addition lets a model combine compatible information without replacing either source. A transformer adds a token embedding to a position embedding so the representation carries both what token this is and where it occurs. Residual connections add a layer's input back to its output, preserving an information path through a deep network. Bias addition shifts every example by learned adjustments.

Addition only makes sense when positions refer to the same coordinate system. Adding two equally long but unrelated vectors can run successfully and still be meaningless.

Magnitude

Magnitude measures vector length. Square each component, add the squares, and take the square root. For [3, 4], the squared components are 9 and 16; their sum is 25; the square root is 5.

Why magnitude matters in AI

Magnitude tells us the overall scale of a vector. It is used to normalize embeddings before comparing their directions, to measure the size of a gradient update, and to detect activations or gradients that are becoming extremely large. Two vectors can point in the same direction while having very different magnitudes, which is why dot product and cosine similarity answer different questions.

03

The dot product turns two vectors into one score

The dot product answers: how strongly do corresponding components align and reinforce one another? Multiply matching positions, then add the products.

Worked example

(1 × 4)+(2 × −1)+(3 × 2)=8

Positive component products raise the score; negative products lower it. The final output is a scalar.

Why one score is useful

A model often needs to collapse many component-by-component comparisons into one decision signal. In a neuron, the score says how strongly the current inputs match that neuron's learned weights. In retrieval, it can rank how well a query vector matches a document vector. In attention, it helps decide how much one token position should use information from another position.

A larger dot product can come from stronger directional alignment, larger magnitudes, or both. When only direction should matter, systems often normalize the vectors and use cosine similarity.

Go deeper: why neural networks use dot products

A neuron treats one vector as inputs and another as weights. Their dot product forms a weighted sum: inputs paired with larger positive weights contribute more, while negative weights suppress the result.

Attention also begins with dot products. A query vector receives a larger score for key vectors that align with it. Later lessons add scaling, masking, and normalization.

04

Matrices transform batches of vectors

A matrix is a two-axis tensor: rows and columns. A data matrix often stores one example per row and one feature per column. Matrix multiplication applies many dot products systematically.

What “transformation” means here

A transformation maps a vector from one representation to another. Multiplying by a learned weight matrix mixes the input components to produce new components. A layer can turn 10 input measurements into 8 learned features, or turn each transformer token vector into separate query, key, and value vectors.

Geometrically, a matrix can stretch, shrink, rotate, reflect, or combine directions. In machine learning, training adjusts the matrix values until that new representation becomes useful for the prediction task. The operation changes the representation; it does not change which example or token the row belongs to.

05

Broadcasting reuses a compatible smaller shape

Imagine a spreadsheet with four customers as rows and three product-category scores as columns. You want to apply the same three learned baseline adjustments to every customer. You could copy the adjustment row four times, but broadcasting lets the system reuse it automatically.

Metaphor: fill the formula down

In a spreadsheet, you write one formula and fill it down a column. Broadcasting is similar: a smaller pattern is reused across a larger axis. The computer does not physically need four stored copies of the bias; it behaves as though the compatible row were repeated.

Where the metaphor stops: broadcasting follows precise shape rules, not spreadsheet cell references.

Read one row before reading the whole tensor

Customer 1 has category scores [2, 0, −1]. The learned baseline is [0.5, −1, 2]. Addition happens by matching columns:

[2, 0, −1] + [0.5, −1, 2] = [2.5, −1, 1]

The same baseline is then applied to customers 2, 3, and 4. Four rows remain four rows, so the output shape stays (4, 3).

1. Align from the right

Batch (4, 3) and bias (3,) both end with 3.

2. Reuse the missing axis

The bias has no customer axis, so it is reused for all 4 customers.

3. Preserve the large shape

The result contains 4 customers × 3 adjusted scores.

WATCH THE REUSE

Convenient does not mean harmless. Shapes can be numerically compatible while their meanings are incompatible. A three-value bias for product categories must not be applied to a three-column tensor representing latitude, longitude, and altitude merely because both end in 3. 06

Embeddings turn useful relationships into geometry

An embedding model converts an object—such as a token, sentence, document, image, or product—into a fixed-length vector. Training places objects with useful relationships near one another or in similar directions according to the model's objective.

Metaphor: a learned map with neighborhoods

On a city map, nearby coordinates represent nearby places. On an embedding map, nearby vectors often represent items the model learned to treat similarly. Hiking boots may occupy a neighborhood near trail shoes; a document about changing a password may lie near the query “I forgot my login.”

Where the metaphor stops: an embedding space may have hundreds or thousands of dimensions, its axes usually have no simple human label, and “nearby” reflects training—not universal truth.

What is actually learned?

The model is trained on examples or objectives that reward useful relationships. It learns a function that assigns coordinates. No engineer manually chooses a “password dimension” or a “shoe dimension”; the useful structure is distributed across many coordinates.

Cosine similarity compares vector direction after accounting for magnitude. Values near 1 indicate similar direction, 0 indicates a right angle, and −1 indicates opposite direction. These are geometric relationships—not confidence percentages and not proof that two items mean the same thing.

Semantic search

A query and a document can be close even when they use different words: “car will not start” may retrieve “troubleshooting a dead battery.”

Recommendations

Products viewed or purchased in similar contexts can develop nearby representations, helping surface related items.

Clustering

Support tickets with similar vector patterns can be grouped before anyone manually defines every possible topic label.

Go deeper: similarity is not understanding

An embedding is learned for an objective and dataset. Nearby vectors indicate similarity according to that training signal, not a universal definition of meaning.

Production retrieval also depends on normalization, distance choice, indexing, metadata filters, data freshness, reranking, and evaluation. A similarity score alone is not proof that a result is relevant.

07

Tensor shapes describe transformer computation

A transformer must keep track of many text sequences, every token position inside each sequence, and the current learned representation at every position. A common activation shape is (batch, sequence, hidden).

Metaphor: trays of annotated index cards

Imagine a batch as a stack of trays. Each tray holds one sentence. Every ordered slot on a tray holds one token card. Written on each card is a list of hidden numeric notes. Transformer layers update the notes as cards exchange relevant information, but the trays and card positions stay organized.

Where the metaphor stops: the “notes” are learned numbers, not human-readable facts, and attention mixes information mathematically rather than moving physical cards.
AXIS 0Batch

How many sequences are processed together. Example: 4 sentences.

AXIS 1Sequence

How many ordered token slots each sequence contains. Example: 8 positions.

AXIS 2Hidden

How many learned values describe each token position. Example: 768 values.

Build the shape one axis at a time

Suppose a tokenizer turns “Models learn patterns.” into five model-specific tokens. To process it efficiently with other sentences, the application pads every sequence in this batch to 8 slots. It groups four padded sequences together. At each slot, the model stores 768 learned values.

4 sequences×8 token slots each×768 values per slot=shape (4, 8, 768)

This tensor contains 24,576 numbers. Padding slots do not contain useful words, so an attention mask tells the model not to treat them as ordinary content.

The token begins as an integer vocabulary ID. Embedding lookup turns that ID into the first hidden vector. Every transformer layer then updates the vector using context from other positions. The token slot stays in place while its representation becomes context-sensitive.

Why batch exists

Processing multiple requests together uses modern accelerators more efficiently, much like loading a dishwasher instead of washing one plate at a time.

Why sequence exists

Order matters: “dog bites person” and “person bites dog” contain the same words but describe different events.

Why hidden exists

One number cannot carry all useful context. The hidden axis gives the model a large workspace for learned patterns.

Transformer layers usually preserve the batch and sequence axes while transforming the hidden axis. Learned matrices project each token vector into queries, keys, and values. Pairwise query-key dot products produce attention scores, allowing each position to decide which other positions matter for its update. Additional prerequisites: comfort tracing matrix dimensions; no programming is required.

Shape compatibility is not semantic compatibility

Two tensors may multiply or broadcast successfully while representing incompatible axes, units, or ordering. Production systems therefore need named contracts, assertions, preprocessing versions, and known-answer tests—not only shape checks.

Memory layout and movement

A tensor also has a data type, device, strides, and memory layout. Transposing can create a different view without immediately copying values, while some kernels later require contiguous storage. At scale, moving tensors between host memory and an accelerator can cost more time than a small calculation.

Precision is an engineering decision

Lower-precision values reduce memory and increase accelerator throughput, but narrow numeric range can overflow, underflow, or erase small updates. Mixed-precision training keeps sensitive operations or master weights at higher precision while accelerating safer operations.

Engineering question: A tensor has the expected shape but retrieval quality collapses after deployment. Which axis semantics, normalization, dtype, and model-version checks would you perform?
