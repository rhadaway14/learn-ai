# Phase 1 Project — Model Investigation Workbench

This browser-first project integrates Lessons 1–5. It assesses reasoning before implementation: prediction framing, prediction-time evidence, leakage, baselines, uncertainty, metrics, thresholds, and production-shaped evaluation.

Open `index.html` through the course link or any static web server. No Python, command line, model download, or Docker service is required.

## Passing contract

- At least 7 of 9 objective decisions are correct, including shape reasoning and optimization evidence.
- Both release-critical decisions (leakage and production split) are correct.
- All three evidence notes use two substantive sentences and at least 18 distinct words. Each must name Northstar, satisfy every prompt-specific evidence category, and express a causal relationship; keyword stuffing and repeated filler are rejected.
- The downloaded JSON artifact records its schema version, persistent attempt number, answers, feedback, evidence, score, and timestamp. Attempt-specific filenames preserve earlier submissions instead of silently replacing them.

The engineer extension in [Project A](../PROJECT_A_CLASSICAL_ML.md) implements the accepted decision after Engineering Lab A introduces the required coding workflow.
